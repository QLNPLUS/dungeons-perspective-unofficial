# Dungeons Perspective Unofficial

《Dungeons Perspective》的非官方 Forge 1.20.1 移植版：把 Minecraft 的第三人称视角改成接近《Minecraft Dungeons》的伪等距视角，保留原版项目的核心思路与操作。

- Minecraft 1.20.1 / Forge 47.2 或更新版本
- 必需运行依赖：Embeddium 0.3.31 或更新版本（不随本仓库分发）
- 上游项目：《Dungeons Perspective》由 cleannrooster/Forg 制作；本项目为非官方移植，与原版作者无隶属或背书关系，原版的正式发布与支持请以原版项目页与上游仓库为准
- 移植维护：QLNPLUS

## 构建

仓库提供 `common`、`fabric`、`forge`、`neoforge` 模块；Forge 1.20.1 的产物命名与发布流程见 `.github/workflows/curseforge-publish.yml`。
